# RunStreak

> **Merged into [LoopDay](https://github.com/tadagambura/loopday).**

Walking and running are now a LoopDay habit type. The NHS Couch to 5K app is free and trusted, and Strava owns Runna, so a standalone GPS run tracker wasn't worth the build.

Decided in the November 2026 portfolio review, based on market research across Reddit, forums,
TikTok/YouTube trends and app-store reviews. This repo is kept for history and is no longer developed.
